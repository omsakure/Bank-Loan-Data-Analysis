# Banking Data Analysis using MS-SQL

This project analyzes banking data to gain insights based on:

- Total Loan Applications  
- Funded Amount  
- Amount Received  

The analysis was performed using **MS-SQL** queries on a structured dataset.

## 📊 Objective

To explore and summarize key metrics from the banking data to better understand loan distribution and repayment performance.

## 🛠️ Technologies Used

- Microsoft SQL Server
- Power BI
